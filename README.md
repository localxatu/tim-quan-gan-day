# Các con vợ muốn đi đâu nào? 🍜

Web tìm quán ăn, cà phê, cây xăng, nhà thuốc, ATM, siêu thị, cửa hàng tiện lợi, trạm sạc xe điện quanh vị trí hiện tại.

## Cách dùng
Mở `index.html` bằng trình duyệt, hoặc bật GitHub Pages (Settings → Pages → Deploy from a branch → main) để lấy link dùng trên điện thoại.

## Tính năng
- Định vị GPS hoặc gõ địa chỉ (có gợi ý tự động)
- 8 nhóm địa điểm, bán kính từ dưới 500m đến trên 4km
- Bản đồ, khoảng cách, nút chỉ đường Google Maps
- Không cần API key

Dữ liệu: OpenStreetMap (cộng đồng đóng góp).
